SandBot JVM sidecar — third-party notices
==========================================

sandbot-sdk.jar contains:

1. Class files of the FIRST Tech Challenge Robot Controller SDK 12.0.0
   (Maven Central: org.firstinspires.ftc:RobotCore, Hardware, FtcCommon, Vision 12.0.0).
   SandBot redistributes the classes whose references close over the JDK and SandBot's own
   implementation ("lifted" classes). Their bytecode is unchanged except that calls to the
   system clock and sleeping (System.nanoTime, System.currentTimeMillis, Thread.sleep, ...)
   are redirected to SandBot's simulated clock.

2. Java sources derived from the same SDK and compiled by SandBot: the public and protected
   API of the remaining SDK classes (method bodies replaced), and SDK classes re-implemented
   for the simulator from the SDK sources (each such source file keeps its original
   copyright header). One of them,
   org.firstinspires.ftc.robotserver.internal.webserver.MimeTypesUtil, comes from the
   RobotServer 12.0.0 sources (org.firstinspires.ftc:RobotServer, 3-Clause BSD); the rest of
   RobotServer is not included.
